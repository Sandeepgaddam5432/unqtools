# UnQTools Cinematic Reel — Remotion

A 60-second vertical 1080×1920 motion-graphics reel, 30fps, using UnQTools midnight/violet/teal branding.

## Render locally
`cd remotion && npm install && npm run render`

Output: `remotion/out/unqtools-reel.mp4`.

## Free cloud render
GitHub Actions workflow **Render UnQTools Reel** can render the MP4 on GitHub-hosted runners and upload it as an artifact. This is a Remotion animation project, not a paid AI-video service. Current cut uses motion graphics and does not yet include recorded voiceover or licensed music.


Render workflow is triggered automatically by changes on the `videos` branch.
