## Track B — UnQ AI (the moat nobody in this space has)

Build a command-bar assistant on top of the 1,679-tool catalog:

1. **Tool router** — user types "compress this PDF and email it" → agent picks the
   right tool, opens it pre-configured. Pure client-side; optional BYO-key LLM.
2. **Chat-with-catalog** — "I need to make a receipt with GST" → answers with the
   exact tool + one-click jump (grounded in manifests, no hallucinated URLs).
3. **Batch mode** — "watermark these 50 images" → chained tool pipeline.
4. Monetization: free basic, premium for batch + advanced AI (BYO-key = zero API cost to us).

  JSON tools) — free tier + paid plans; agencies/CA firms/colleges integrate.
