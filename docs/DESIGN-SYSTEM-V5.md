## Deviations from skill output (with reasons)

### 1. Light + Dark parity (skill said "Dark Only")

**Deviation:** We support BOTH light and dark modes with full parity.
**Reason:** Product requirement: "everything works light + dark." WCAG AA must pass in both modes.

### 2. Primary color: Apple blue #0071e3 (skill said #1E3A5F)

**Deviation:** Keep existing Apple blue as primary CTA accent.
**Reason:** Owner approved Apple blue in v2.1. Navy #1E3A5F reduces CTA vibrancy. Skill palette adopted for dark backgrounds/surfaces.

### 3. Accent green #22C55E adopted for success (skill recommendation)

**Deviation:** Adopt #22C55E as success/positive accent, keep #0071e3 as primary CTA.
**Reason:** Green as primary CTA is unusual for tool directories. Blue is convention for "action."

### 4. Uniform CSS Grid (skill said Portfolio Grid masonry)

**Deviation:** Uniform grid, not masonry.
**Reason:** Tool cards have equal-height content. Masonry is for variable-height visuals.

### 5. Dark background colors adopted

**Status:** #0F172A bg, #10192E muted, #334155 secondary, rgba(255,255,255,0.08) border — all adopted for dark theme.

### 6. Minimal glow effects adopted

**Status:** text-shadow glow on hero keyword, dark-to-light transitions, ambient aura — all adopted.
